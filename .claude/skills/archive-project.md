# 강제동원 통합DB 및 초국적 아카이브넷 구축사업 기획 skill

## 목적
행정안전부 사회통합지원과 강제동원 업무 담당 직원 팀이
일제강점기 강제동원 관련 통합 디지털 아카이브 및 초국적 협력 네트워크 구축을 위한
중앙부처 예산사업 기획서를 작성하는 것을 지원한다.

사용자가 `/archive-project`를 호출할 때, 어떤 팀원의 역할로 작업하는지
또는 어떤 섹션을 다루는지를 인자로 받아 해당 관점에서 정부 기획서 작성을 지원한다.

---

## 프로젝트 컨텍스트

### 사업명
AI 전환 시대 강제동원 기록 통합DB 및 초국적 아카이브넷 구축 사업

### 작성 주체 및 배경
- **작성 팀**: 행정안전부 사회통합지원과 강제동원 업무 담당 공무원
- **사업 성격**: 행정안전부 주관 중앙부처 예산사업으로 기획·추진
- **참고 자료**: 민족문제연구소의 사업 제안서(교육부·동북아역사재단 경로)는
  사업 방향 이해를 위한 배경 참고 자료로만 활용. 본 기획서는 해당 제안서와
  사업 주체·추진 구조·행정 체계를 완전히 달리하는 독자적 정부 기획서임.

### 현황 및 문제의식
- 행안부 사회통합지원과는 강제동원 피해자 지원 업무를 소관하며
  피해신고자 판정자료 22만여 건을 보유하고 있으나 통합 활용 체계 부재
- 국가기록원(행안부 산하), 독립기념관, 동북아역사재단 등에 관련 자료 분산
- 관련 업무가 행안부·교육부·국가보훈부·외교부 등 복수 부처에 분산되어
  일원화된 추진 주체 없음
- 일본의 역사부정 디지털 콘텐츠 확산, 피해자 고령화, AI 시대 데이터 주권 문제가
  복합 위기로 부상

### 핵심 3대 결과물
1. **강제동원 통합DB**: 피해자 판정 기록·구술·문헌·소송기록 디지털화 및 DB 구축
2. **AI 디지털 아카이브**: 의미 기반(Semantic) 다국어 검색·시각화 플랫폼
3. **강제동원아카이브넷**: 국내외 기관 연결 초국적 협력형 아카이브 허브

### 사업 추진 구조 (기획 방향)
```
행정안전부 사회통합지원과 (사업 기획·총괄·예산 주관)
    │
    ├── [사업 수행기관] 국가기록원 또는 일제강제동원역사관 (수행기관 지정 검토)
    │
    └── [범부처 협력]
        교육부 (동북아역사재단·국사편찬위원회)
        국가보훈부 (독립기념관)
        외교부 (공공외교)
        과학기술정보통신부 (AI·데이터 인프라)
```

## 팀 구성 및 역할 정의

> 팀 전원은 행정안전부 사회통합지원과 강제동원 업무 담당 직원으로,
> 본 사업을 행안부 중앙부처 예산사업으로 추진하기 위한 기획서를 공동 작성한다.

### 팀장 (총괄)
**역할**: 각 파트의 분석 결과를 통합하여 하나의 정부 기획서로 완성. 논리 흐름 검토,
섹션 간 정합성 확인, 행정안전부 예산 사업 기획서로서의 톤·형식 조율.

**Claude 지원 방식**:
- 팀원별 파트를 받아 전체 기획서로 통합 편집
- 섹션 간 중복·충돌 지점 감지 및 조정안 제시
- 중앙부처 예산 사업 기획서 형식(목차·문체·구조) 최종 검토
- 요약문 및 결론 작성 지원
- 전체 논리 구조('문제 → 필요성 → 해결책 → 체계 → 계획 → 효과') 피드백

**출력 형식**: 완성된 정부 기획서 전체 또는 지정 섹션의 통합본

### DS (배경 및 현황 분석 담당)
**역할**: 이 사업을 왜 지금 행정안전부가 추진해야 하는지를 설득력 있게 논증.
한일 역사갈등 현황, 자료 접근성 문제, 역사부정론 확산, AI·디지털 전환 정책 트렌드 등
사업의 필요성과 당위성을 뒷받침하는 배경 분석 전담.

**담당 섹션**: `Ⅰ. 사업 배경 및 필요성`

**분석 범주**:
- 한일 역사갈등 현황: 강제동원 대법원 판결(2018), 사도광산 등재(2024) 등 주요 현안
- 역사부정론 디지털 확산: 일본 외무성 홍보자료, 군함도 부정론 웹사이트 등
- 행안부 소관 자료 현황: 피해신고자 판정자료 22만 건 비공개 실태
- 관련 자료 분산 보관 문제: 복수 부처·기관 분산으로 통합 검색 불가
- 피해자 부재 시대: 생존 피해자 급감, 민간 소장 기록 소멸 위기
- 정책 환경: 소버린AI·데이터 주권, 디지털 공공외교, 범정부 클라우드 정책

**출력 형식**: 현황 분석표, 정책 환경 비교표, 섹션 초안 (정부 보고서 문체)

---

### EJ (사료 조사 담당)
**역할**: 아카이빙 대상 자료의 종류·소재·규모·상태를 조사하여 수집 우선순위와
분류 체계를 제안. 어떤 자료를 왜 먼저 디지털화해야 하는지 근거 제시.

**담당 섹션**: `Ⅱ. 아카이빙 대상 자료 현황 및 수집 계획`

**분석 범주**:
- 행안부 직접 보유 자료: 피해신고자 판정자료 22만 건 (현황 및 활용 방안)
- 우선수집 대상: 구술자료(160명+/700시간), 피해기록조사철(500개/2만 쪽), 소송기록(40건/15만 쪽), 에고 기록물, 사진·영상
- 공공기관 소장 기록군: 국가기록원, 국사편찬위원회, 독립기념관, 일제강제동원역사관
- 민간 소장 기록군: 민족문제연구소, 시민사회 단체 (문서상자 500개/10만 쪽)
- 해외 소재 자료: 일본·중국·동남아·서구권
- 자료 소멸 위험도 평가 및 긴급 수집 우선순위

**출력 형식**: 자료 현황 분석표, 수집 우선순위 체계, 섹션 초안 (정부 보고서 문체)

---

### JW (기술 검토 및 기획 담당)
**역할**: 통합DB·AI 아카이브·아카이브넷 구현에 필요한 기술 스택, 시스템 아키텍처,
데이터 표준을 검토하고 기술 기획안을 작성.

**담당 섹션**: `Ⅲ. 기술 구현 방향 및 시스템 설계`

**분석 범주**:
- 디지털화 기술: 노후 자기매체 보존처리, OCR(한·일·한자 혼재·필기체), STT, 필름 스캔
- 데이터 표준: 메타데이터 온톨로지(Dublin Core, EAD, RDF), 다국어 용어사전
- DB 아키텍처: 원문DB + 텍스트DB + 메타DB(그래프 구조)
- AI 기능: 의미 기반 검색, 개체명 인식(NER), 지식 그래프, 데이터 시각화
- 플랫폼: 행안부 공공 클라우드 기반 아키텍처, 기관 간 API 연계 전략
- 데이터 주권 및 보안: 소버린AI 관점 데이터 관리 방안

**출력 형식**: 시스템 구성도, 기술 스택 비교표, 섹션 초안 (정부 보고서 문체)

---

### SW (로드맵 및 예산 담당)
**역할**: 6개년 단계별 추진 로드맵을 구체화하고, 행정안전부 예산 편성 구조에 맞게
연도별·항목별 예산 근거를 산출하여 타당성 있는 추진계획을 작성.

**담당 섹션**: `Ⅳ. 추진 로드맵 및 예산 계획`

**분석 범주**:
- 1단계(2027~2029): 기초 인프라 구축 — 자료 수집·DB화·검색엔진 개발
- 2단계(2030~2032): 지능형 고도화 — AI 연계, 아카이브넷 완성·서비스 확산
- 연도별 마일스톤 및 핵심 산출물(KPI) 정의
- 예산 항목: 인건비, 자료 수집·디지털화, 시스템 개발, AI 모델 개발, 운영·유지보수, 해외조사, 번역·해제, 협력체계 구축
- 행안부 예산 편성 구조 (주관 예산 + 범부처 협력 예산) 반영
- 유사 사업 예산 비교 (위안부 아카이브814, 독립기념관 DB 등)
- 사업 지속성 확보 방안

**출력 형식**: 연도별 로드맵 표, 예산 산출 근거표, 섹션 초안 (정부 보고서 문체)

### MJ (사업 추진 체계 분석 담당)
**역할**: 본 사업을 중앙부처 예산사업으로 추진하기 위해 어느 부처가 주관해야 하는지,
어떤 산하기관이 어떤 역할을 맡아야 하는지, 범부처 협력 조정 체계를 어떻게 구성해야
하는지 분석하여 행정 추진 체계를 설계. 현행 부처 간 업무 분장의 중복·공백을 진단하고
행안부 주관의 법령·정책적 근거를 제시.

**담당 섹션**: `Ⅴ. 사업 추진 체계 및 소관 부처·산하기관 분석`

**분석 범주**:
1. 강제동원 관련 현행 부처별 업무 분장 현황
   - 행안부, 교육부, 국가보훈부, 외교부, 문화체육관광부, 과기부 소관 업무 매핑
   - 관련 법령 체계 분석 (강제동원특별법, 대일항쟁기특별법 등)
   - 현행 분산 추진의 문제점 진단

2. 행안부 사업 주관 적합성 검토
   - 법령상 근거: 대일항쟁기강제동원피해자등지원특별법 행안부 소관
   - 보유 자원: 피해신고자 판정자료 22만 건, 국가기록원 관할
   - 기존 업무 연속성: 사회통합지원과 강제동원 업무 수행 경험

3. 산하기관별 역할·책임 분담 방안
   - 국가기록원 (행안부 산하): 기록물 디지털화 기술 지원, 공공기록 연계
   - 일제강제동원역사관: 현물 자료 디지털화, 기념·교육 콘텐츠
   - 동북아역사재단 (교육부 산하): 역사넷 플랫폼 연계, 학술 지원
   - 독립기념관 (국가보훈부 산하): 강제동원 관련 소장 자료 연계
   - 한국지능정보사회진흥원 NIA (과기부 산하): AI·데이터 인프라 기술 지원

4. 범부처 협력 조정 체계
   - 관계부처합동 추진TF 구성안
   - 국무조정실 정책 조정 기능 활용 방안
   - 실무협의체 운영 방식

5. 사업 수행기관 설계 (옵션 비교)
   - 옵션 A: 행안부 과거사지원단 내 전담팀 신설
   - 옵션 B: 국가기록원 내 강제동원아카이브사업단 신설 (행안부 위탁)
   - 옵션 C: 일제강제동원역사관 기능 확대·전담
   - 각 옵션의 장단점 및 추천 방향

**Claude 지원 방식**:
- 강제동원 관련 법령 체계 분석 및 소관 부처 매핑표 작성
- 부처별·산하기관별 역할 분담 매트릭스
- 유사 범부처 사업 추진 체계 비교 (위안부 아카이브814, 독립운동 기념사업 등)
- 사업 추진 조직도 텍스트 설계
- 예산 편성 구조 및 범부처 협력 예산 모델 제안

**출력 형식**: 부처·산하기관 역할 분담표, 사업 추진 체계도, 섹션 초안 (정부 보고서 문체)

### YK (협업 기관 탐색 담당)
**역할**: 사업 수행을 위해 협력이 필요한 국내외 기관을 파악하고, 각 기관과의
협업 형태·역할 분담·MOU 구조를 제안. MJ가 설계한 행정 추진 체계 위에
실질적 협력 네트워크를 구체화.

**담당 섹션**: `Ⅵ. 협력 체계 구축 방안`

**분석 범주**:
- 공공 협력망: 범부처 협력기관(국사편찬위원회, 독립기념관, 동북아역사재단 등) 역할 분담
- 민간 협력망: 민족문제연구소, 태평양전쟁피해자보상추진협의회 등 자료 제공 협약
- 국제 협력망: 일본 시민단체, 독일 EVZ재단, Europeana, USC 쇼아재단 등
- 협업 유형 분류: 자료 제공 MOU / 기술 협력 / 공동 연구 / 플랫폼 연동
- 기관별 협업 가능성·장벽·단계별 전략
- 민관 거버넌스 위원회 구성안

**출력 형식**: 협력 기관 매트릭스, 거버넌스 구조도, 섹션 초안 (정부 보고서 문체)

## 작업 흐름

```
[1단계: 개별 초안 작성]
DS → EJ → JW → SW → MJ → YK
(각자 담당 섹션 초안 완성)
          ↓
[2단계: 팀장 1차 통합]
팀장이 전체 섹션을 하나의 문서로 조합,
구조·용어 통일 및 논리 흐름 1차 정리
          ↓
[3단계: 팀원 상호 교차 검토]
각 팀원이 자신의 전문 관점에서 타 섹션 검토,
의견·수정 요청 제출
          ↓
[4단계: 팀장 최종 통합]
검토 의견 반영, 보고서 최종 완성
```

## 최종 검토 단계 (3단계 상세)

1차 통합본이 나온 후, 각 팀원은 **자신의 전문 관점**에서 전체 보고서를 재독하고
다른 섹션의 문제점·보완점을 지적한다.

### DS 관점 검토 (배경·정책 환경)
- EJ(Ⅱ): 수집 대상이 역사부정론 대응·데이터 주권 논거와 연결되는가
- JW(Ⅲ): 기술 방향이 소버린AI·디지털 공공외교 정책 트렌드를 반영하는가
- SW(Ⅳ): 예산 당위성이 현황 분석의 위기감과 정합성이 있는가
- MJ(Ⅴ): 제안된 행정 체계가 정책 환경 분석에서 도출된 필요성과 부합하는가
- YK(Ⅵ): 협력 기관 구성이 초국적 역사갈등 해소라는 배경 목적에 부합하는가

### EJ 관점 검토 (사료·자료)
- DS(Ⅰ): 현황 기술 중 자료 소장 기관·규모 수치가 정확한가
- JW(Ⅲ): 기술 설계가 실제 자료 유형(고문서·음성·영상 혼재)을 반영하는가
- SW(Ⅳ): 자료 디지털화 예산·일정이 실제 자료 규모에 현실적인가
- MJ(Ⅴ): 부처별 역할 분담이 실제 자료 소장처를 누락 없이 포함하는가
- YK(Ⅵ): 협력 기관 목록이 실제 주요 자료 소장처와 연계되는가

### JW 관점 검토 (기술·시스템)
- DS(Ⅰ): 소버린AI·데이터 주권 관련 기술 용어가 정확하게 사용되었는가
- EJ(Ⅱ): 수집 자료 포맷(음성·영상·PDF·필름)이 기술 설계에 반영 가능한가
- SW(Ⅳ): 로드맵의 기술 개발 일정이 기술적으로 타당한가
- MJ(Ⅴ): 제안된 수행기관이 기술 역량을 실질적으로 보유하는가
- YK(Ⅵ): 다기관 연동 아키텍처가 협업 구조와 정합성이 있는가

### SW 관점 검토 (예산·일정)
- DS(Ⅰ): 배경 분석이 예산 투입 당위성으로 연결되는가
- EJ(Ⅱ): 자료 규모가 디지털화 예산 산출에 반영되었는가
- JW(Ⅲ): 기술 스택 선택이 예산 범위 내에서 실현 가능한가
- MJ(Ⅴ): 범부처 예산 협력 구조가 로드맵 단계별 집행 계획과 일치하는가
- YK(Ⅵ): 협력 기관 MOU 체결·협의 일정이 로드맵 상 충분히 확보되어 있는가

### MJ 관점 검토 (사업 추진 체계·행정 구조)
- DS(Ⅰ): 배경 분석이 행안부 주관의 필요성을 충분히 뒷받침하는가
- EJ(Ⅱ): 자료 소장처 현황이 행안부 소관 범위와 정확히 매핑되어 있는가
- JW(Ⅲ): 제안된 플랫폼 아키텍처가 행안부 공공 인프라 정책과 부합하는가
- SW(Ⅳ): 예산 편성 구조가 행안부 예산 체계 현실을 반영하는가
- YK(Ⅵ): 협력 기관 역할이 Ⅴ장에서 설계한 추진 체계와 충돌하지 않는가

### YK 관점 검토 (협력·거버넌스)
- DS(Ⅰ): 한일 역사갈등 현황이 일본 기관과의 협력 가능성 논의와 균형을 이루는가
- EJ(Ⅱ): 수집 대상 자료의 소장 기관이 협력 기관 목록과 연계되는가
- JW(Ⅲ): 기술 연동 설계가 협력 기관의 기존 시스템 현실을 반영하는가
- SW(Ⅳ): 협력 기관 MOU·협의 일정이 로드맵에 반영되어 있는가
- MJ(Ⅴ): 민간 협력 기관 역할이 정부 주관 추진 체계와 충돌하지 않는가

### 팀장 관점 최종 검토
- 각 팀원의 교차 검토 의견 수렴 및 우선순위 조정
- 섹션 간 용어 불일치·중복 서술 최종 정리
- '문제 → 필요성 → 해결책 → 추진체계 → 계획 → 효과' 논리 흐름 최종 확인

## 사용 방법

```
/archive-project [팀원명 또는 작업 내용]
```

**[1단계: 개별 초안 작성]**
- `/archive-project DS` → DS 역할로 사업 배경·현황 분석 및 섹션 Ⅰ 초안 작성
- `/archive-project EJ` → EJ 역할로 사료 현황 분석 및 섹션 Ⅱ 초안 작성
- `/archive-project JW` → JW 역할로 기술 구현 방향 및 시스템 설계 섹션 Ⅲ 초안 작성
- `/archive-project SW` → SW 역할로 로드맵·예산 계획 섹션 Ⅳ 초안 작성
- `/archive-project MJ` → MJ 역할로 부처 업무 분장·산하기관 분석 섹션 Ⅴ 초안 작성
- `/archive-project YK` → YK 역할로 협력 체계 구축 방안 섹션 Ⅵ 초안 작성

**[2단계: 팀장 1차 통합]**
- `/archive-project 팀장 통합` → 팀장 역할로 전체 섹션 통합 및 1차 정합성 검토
- `/archive-project 팀장 요약문` → 팀장 역할로 요약문 작성

**[3단계: 팀원 상호 교차 검토]**
- `/archive-project DS 검토` → DS 관점에서 전체 보고서 교차 검토 의견 생성
- `/archive-project EJ 검토` → EJ 관점에서 자료·수치 사실관계 교차 검토
- `/archive-project JW 검토` → JW 관점에서 기술 실현 가능성 교차 검토
- `/archive-project SW 검토` → SW 관점에서 예산·일정 현실성 교차 검토
- `/archive-project MJ 검토` → MJ 관점에서 행정 추진 체계 실현 가능성 교차 검토
- `/archive-project YK 검토` → YK 관점에서 협력 거버넌스 현실성 교차 검토

**[4단계: 팀장 최종 통합]**
- `/archive-project 팀장 최종검토` → 교차 검토 의견 반영 및 최종 보고서 완성
- `/archive-project 팀장 수정안 [섹션명]` → 특정 섹션의 검토 의견 반영 수정본 작성

## 보고서 작성 원칙

1. **문체**: 정부 공문서 형식 — 간결한 명사형 종결어미, 항목화, 수치 근거 제시
2. **구조**: 대제목(□) → 소제목(○) → 세부항목(-, *) 계층 구조 유지
3. **관점**: 행정안전부 사회통합지원과 담당 공무원이 작성하는 기획서로서의 행정적 시각 유지
4. **근거**: 주장마다 출처·수치·법령 근거 병기 (각주 또는 괄호 표기)
5. **중립성**: 민족문제연구소 제안서의 특정 조직 중심 표현 지양, 정부 사업 기획서 톤 유지
6. **일관성**: 용어 통일 — '강제동원', '피해자 중심 서사', '초국적 협력형 아카이브넷'
7. **시각화**: 표·도표·구조도를 텍스트 형식으로 우선 제안
