## 요약문

□ **사업 개요**
  한일 과거사(강제동원·일본군'위안부'·독도·역사교과서·식민피해·약탈문화재) 관련 기록을
  한곳에 모아 디지털로 정리하고, 국내외 기관을 연결하는 「한일과거사 AI 아카이브넷」을
  만드는 6년(2027~2032) 사업

□ **추진 배경**
  ○ 같은 한일 과거사인데도 자료가 6개 부처에 흩어져 있어 한 번에 찾아볼 수 없음
  ○ 일본은 이미 자기 입장의 디지털 자료관을 분야별로 만들어 운영 중
  ○ 피해자 고령화로 증언·기록이 소멸 위기
  ○ AI 시대에 우리 자료가 없으면, AI가 일본 입장으로 역사를 설명할 우려

□ **차별성**
  분야 칸막이를 없애고, 사람 이름 하나로 강제동원·원폭·소송 자료를 한 번에 찾는
  'AI 통합 검색' 제공

□ **추진 체계**
  국무조정실 총괄, 행정안전부(국가기록원) 실무 수행,
  교육부·외교부·국가보훈부·문체부·과기부 분야별 협력

□ **사업 규모**
  6년간 총 48억 원(연 8억 원), 분야별 부처 분담

## Ⅰ. 사업 배경 및 필요성

### 1. 사안 횡단적 성격의 한일 과거사 갈등

□ 강제동원·위안부·독도·교과서 문제는 별개가 아니라 '일본의 식민지배 책임 부정'이라는
  하나의 뿌리에서 나온 서로 연결된 문제입니다.

  ○ 최근 주요 갈등 (분야가 서로 얽혀 있음)

| 연도 | 사건 | 관련 분야 |
|------|------|-----------|
| 2014 | 일본 교과서 검정기준 개정 ('강제연행'·'종군위안부' 삭제) | 교과서 |
| 2015 | 메이지산업유산 등재 / 한일 위안부 합의 | 강제동원·위안부 |
| 2018 | 강제동원 대법원 판결 (일본 기업 배상 책임 인정) | 강제동원 |
| 2021 | 일본 각의결정 ('강제연행'·'위안부' 표현 삭제) | 교과서·강제동원·위안부 |
| 2024 | 사도광산 유네스코 등재 (강제동원 기술 미흡) | 강제동원 |

  ○ 일본은 하나의 논리로 여러 분야를 한꺼번에 공격하는데, 우리는 분야별·부처별로
    따로 대응하고 있어 힘이 분산됩니다.

### 2. 부처별로 분산된 자료와 통합 시스템 부재

□ 한일 과거사 자료가 분야마다 다른 부처·기관에 흩어져 있습니다.

| 분야 | 주로 맡는 부처 | 주요 자료 |
|------|----------------|-----------|
| 강제동원 | 행정안전부 | 피해자 판정자료 22만 건, 강제동원자명부 |
| 일본군'위안부' | 여가부·외교부 | 피해자 증언·소송 기록 |
| 독도 | 외교부·교육부 | 옛 지도, 외교문서 |
| 역사교과서 | 교육부 | 검정자료, 왜곡 대응 자료 |
| 식민피해 | 행안부·국가보훈부 | 관동대지진·사할린·원폭 피해 명부 |
| 약탈문화재 | 문체부 | 약탈문화재 소재 목록 |

  ○ 독도·위안부는 분야별 자료관이 일부 있지만 서로 연결되어 있지 않고, 강제동원 등은
    통합 자료관 자체가 없습니다.
  ○ 특히 행정안전부가 가진 강제동원 피해자 판정자료 22만 건은 활용할 법적 근거가
    부족해 사실상 잠자고 있습니다.

### 3. 역사부정론의 디지털 확산

□ 일본 정부와 우익 단체는 강제동원·위안부·독도 각 분야마다 부정 전용 웹사이트·홍보자료를
  만들어 국제 사회에 자기 주장을 퍼뜨리고 있습니다.

  ○ 우리가 반박하려면 피해자 증언·원본 문서·재판 기록 같은 '증거 자료'가 한곳에 모여
    누구나 볼 수 있어야 하는데, 지금은 흩어져 있어 제대로 대응하지 못합니다.

### 4. 피해자 부재 시대의 기록 소멸 위기

□ 생존 피해자가 고령으로 급감하면서, 이제는 '증언'이 아니라 '기록'으로 역사를 이어가야
  하는 시대가 되었습니다.

  ○ 시민단체가 수십 년간 모은 구술 녹음·일기·편지 등은 단체 해산·고령화로 버려지거나
    사라질 위험에 처해 있습니다. 한 번 없어지면 되살릴 수 없습니다.

### 5. AI 전환 시대의 데이터 주권과 사업 당위성

□ 요즘 AI는 인터넷에 있는 글을 학습해 답을 만듭니다. 한국 측 과거사 자료가 부족하면,
  AI가 일본 입장으로 역사를 설명하게 될 수 있습니다.

  ○ 그래서 우리 피해자 중심의 자료를 디지털로 잘 정리해 'AI가 배우는 자료'로 제공하는 것이
    중요합니다. 이것이 '소버린 AI(자국 데이터로 만든 우리만의 AI)' 시대의 과제입니다.
  ○ 독일은 이미 26개국 강제노동 피해자 자료관을 만들었고, 일본도 자기 입장의 자료관을
    먼저 만들어 두었습니다. 우리도 더는 미룰 수 없습니다.

## Ⅱ. 아카이빙 대상 자료 현황 및 수집 계획

### 1. 6대 도메인별 자료 현황 및 우선순위

| 분야 | 핵심 자료 | 사라질 위험 |

| 강제동원 | 피해자 판정자료, 구술, 소송기록 | 높음 |
| 일본군'위안부' | 피해자 증언, 소송기록 | 매우 높음 |
| 독도 | 옛 지도, 외교문서 | 낮음(보존 양호) |
| 역사교과서 | 검정자료, 왜곡 대응 자료 | 낮음 |
| 식민피해 | 관동대지진·사할린·원폭 피해 명부 | 높음 |

  ○ **나중에 연계**: 보존 상태가 좋은 독도·교과서·문화재 자료는 이미 있는 자료관과
    연결하는 방식으로 진행합니다.

### 2. 우선 수집 대상: 구술·개인기록·소송기록

□ 구술 녹음 (피해자가 직접 말한 증언)
  ○ 강제동원·위안부·원폭 피해자 증언 녹음·영상. 오래된 카세트테이프·비디오테이프가 많아
    지금 처리하지 않으면 못 듣게 됩니다.

□ 개인 기록 (일기·편지·수첩)
  ○ 사라질 위험이 가장 큰 자료입니다. 피해자·활동가가 돌아가시거나 단체가 해산하면 바로
    버려집니다.

□ 소송 기록
  ○ 강제동원·위안부 피해자가 한국·일본 법원에 낸 재판 자료. 피해 사실을 법적으로 입증하는
    핵심 증거입니다. (강제동원만 약 15만 쪽)

## Ⅲ. 기술 구현 방향 및 시스템 설계

> 이 장은 '무엇을, 왜'를 중심으로 쉽게 설명합니다.
> 구체적인 기술 사양(해상도·표준 규격 등)은 **부록 5**에 따로 담았습니다.

### 1. 자료 디지털화 방향

□ **오래된 녹음·영상부터 살립니다 (가장 급함)**
  ○ 카세트테이프·비디오테이프는 시간이 지나면 못 쓰게 되므로, 디지털로 바꾸기 전에 먼저
    복원·보존 처리를 합니다.

□ **옛 문서는 스캔한 뒤 글자로 바꿉니다**
  ○ 'OCR(스캔한 사진을 컴퓨터가 읽는 글자로 바꾸는 기술)'을 사용합니다.
  ○ 일본어 옛 글씨·손글씨는 일반 기술로는 안 되므로 전용 기술을 따로 개발합니다.

□ **녹음은 받아쓰기로, 옛 지도·사진은 고화질로**
  ○ 구술 녹음은 'STT(음성을 글자로 바꾸는 받아쓰기 기술)'로 글자화한 뒤 전문가가 교정합니다.
  ○ 독도 옛 지도·필름은 전용 스캐너로 고화질 디지털화합니다.

### 2. 자료 정리 및 연결 체계

□ **자료마다 꼬리표를 붙입니다**
  ○ 모든 자료에 '누가·언제·어디서·무엇을'이라는 정보(메타데이터)를 붙여, 컴퓨터가 찾고
    연결할 수 있게 합니다.

□ **흩어진 자료를 같은 사람·사건으로 묶습니다**
  ○ 인물·사건·장소를 서로 잇는 '지식 구조(온톨로지)'를 설계합니다. 같은 사람의 자료가
    여러 곳에 흩어져 있어도 자동으로 한데 묶입니다.
  ○ 한국어·일본어·영어 용어사전을 함께 만듭니다.
    (데이터 표준·지식 구조 상세 → **부록 5**)

### 3. AI 기반 검색·연결 기능

□ **뜻으로 찾는 검색 (이 사업의 핵심)**
  ○ 단어가 정확히 같지 않아도 '뜻이 통하는' 자료를 찾아줍니다.
    예: 피해자 이름 하나를 넣으면 강제동원·원폭·소송 자료를 분야 구분 없이 한 번에 보여줍니다.
  ○ 한국어로 물어도 일본어·영어 자료까지 찾아줍니다.

□ **자동 연결과 관계도**
  ○ 자료 속 사람·장소·기관 이름을 AI가 자동으로 찾아 표시합니다.
  ○ 인물–사건–자료를 선으로 잇는 '관계도'로 한눈에 살펴볼 수 있습니다.
  ○ 피해 지역 지도, 연도별 통계도 그림으로 보여줍니다.

### 4. 시스템 구성 및 자료 보관 원칙

□ 전체 구성 (간단히)

```
[흩어진 자료]  →  [한곳에 모아 정리(통합DB)]  →  [AI가 찾고 연결]  →  [누구나 쓰는 누리집]
 6대 분야 기관        꼬리표·지식구조로 정리        뜻으로 찾는 검색       시민·연구자·해외 이용자
```

□ **자료는 국내 정부 서버에 안전하게 보관합니다**
  ○ 민감한 피해자 자료는 해외 서버에 두지 않고 국내 정부 클라우드(G-Cloud, 정부가 운영하는
    국내 서버)에 보관합니다. — 우리 데이터를 우리가 지키기 위함입니다.
  ○ AI도 가능한 한 국산 기술을 우선 사용합니다.

## Ⅳ. 추진 로드맵 및 예산 계획

### 1. 단계별 추진 계획 (2027~2032)

□ **1단계 (2027~2029): 기반 만들기**
  ○ 2027: 6대 분야 자료 전수 조사, 실무조직 확정, 부처 협력기구 출범, 급한 녹음테이프 보존
  ○ 2028: 자료 정리 체계 확정, 시범 자료관 구축, 구술·소송기록 디지털화, 검색 시범판

## Ⅴ. 사업 추진 체계 및 소관 부처·산하기관 분석

### 1. 부처별 분산 추진의 문제점

□ 한일 과거사 업무가 분야마다 다른 부처로 나뉘어, 전체를 책임지고 이끄는 곳이 없습니다.
  그래서 비슷한 자료관을 부처마다 따로 만들고, 서로 연결도 안 됩니다.
  (분야별 소관 부처·법령·기관 전체표 → **부록 1**)

### 2. 범정부 추진 + 행안부 실무 수행 체계

□ **총괄은 국무조정실, 실무는 행정안전부(국가기록원)가 맡습니다.**

  ○ 한일 과거사는 한 부처가 다 못 하므로, 여러 부처를 조정하는 **국무조정실**이 총괄합니다.
  ○ 실제 자료관을 만들고 운영하는 일은 **국가기록원(행안부)**이 맡는 것이 가장 적합합니다.

□ 왜 행안부(국가기록원)가 실무를 맡나?

| 이유 | 설명 |
|------|------|
| 법적 권한 | 국가기록원이 공공기록물 디지털화·관리의 법적 책임 기관 |
| 핵심 자료 보유 | 강제동원 판정자료 22만 건 등 가장 많은 과거사 자료 보유 |
| 기술·장비 보유 | 대규모 스캔·보존 장비와 전문 인력을 이미 갖춤 |
| 중립적 위치 | 특정 분야에 치우치지 않는 기록 관리 기관 |

  ○ 다만 역사 연구·국제 대응은 교육부(동북아역사재단·국사편찬위)·외교부가 함께 돕습니다.

### 3. 부처별 역할 분담

| 주체 | 역할 |
|------|------|
| 국무조정실 | 전체 총괄·부처 조정 |
| 행안부 / 국가기록원 | 실무 총괄, 자료관 구축·운영, 강제동원·식민피해 자료 |
| 교육부 / 동북아역사재단·국사편찬위 | 독도·교과서 자료, 역사 자문 |
| 외교부 | 위안부·독도 국제 대응, 해외 자료 조사 지원 |
| 국가보훈부 / 독립기념관 | 식민피해 자료 |
| 문체부 / 국외소재문화유산재단 | 약탈문화재 자료 |
| 과기부 / NIA | AI·데이터 기술 지원 |

### 4. 부처 협력기구 구성

```
[총괄] 국무조정실 「한일과거사 통합아카이브 추진위원회」 (관계부처 차관급)
   │
   ├── [실무] 행정안전부·국가기록원 (간사)
   └── [분야별 실무팀] 강제동원·식민피해 / 위안부 / 독도·교과서 / 문화재 / 기술
```

  ○ 추진위원회는 반기 1회, 분야별 실무팀은 분기 1회 모입니다.

□ **함께 추진해야 할 숙제: 법 정비**
  ○ 강제동원 판정자료 22만 건은 현재 법(개인정보 보호법 등)상 전면 공개가 어렵습니다.
    사업과 함께 법을 정비해야 합니다. (2027 연구 → 2028 입법 → 2029 단계적 공개)

### 5. 사업 수행기관(사무국) 설계

□ 여러 방안을 검토한 결과, **국가기록원 안에 전담팀을 새로 만드는 방안**을 권고합니다.

  ○ 이유: 대규모 디지털화 경험·장비·인력을 이미 갖추었고, 정부 클라우드 연결이 쉬우며,
    책임 소재가 분명하기 때문입니다. 부족한 역사·국제 전문성은 다른 기관 협력으로 채웁니다.
    (검토한 4개 방안 비교 → **부록 5**)

□ 디지털화 기술 세부

  ○ 노후 자기매체 보존처리
    - 카세트·VHS·베타캠 등은 열화 진행 중으로 디지털화 전 물리적 보존처리 선행 필수
    - 점착성 증후군(Sticky Shed Syndrome) 발생 테이프는 전문 보존처리 후 재생
    - 처리 원본은 항온항습(15~18℃, 습도 35~45%) 환경에 이관 보관

  ○ 문서 OCR: 고해상도 스캔(600dpi 이상) 후 다언어 OCR 적용. 일본어 필기체·변체한자는
    전용 모델 별도 구축(fine-tuning). OCR 후처리 전문가 교정 비용 별도 산정

  ○ 음성 STT: 한·일·방언 처리 가능 모델 적용 후 전문가 교정. 전사 텍스트는 AI 학습용
    공개 형식으로 병행 출력

  ○ 고지도·필름: 전용 스캐너(2400dpi 이상) 운용(일반 문서 스캐너와 장비·비용 상이)

□ 데이터베이스 및 메타데이터 표준

  ○ 원문DB(원본 파일·무결성 관리) / 텍스트DB(추출 텍스트·번역·해제) / 메타DB(기술정보·관계)
  ○ 국제 표준 준수: Dublin Core(기본), EAD(아카이브 기술), RDF/OWL(의미 연결)
  ○ 공통+특화 2층 온톨로지 구조

    ```
    [공통 핵심 개체]
    인물(Person) / 사건(Event) / 장소(Place) / 기록물(Document) / 기관(Organization)

    [도메인 특화 확장]
    강제동원: 동원 사업장, 동원 경위
    위안부: 위안소, 이송 경로
    독도: 고지도, 영유권 근거
    문화재: 반출 경위, 현 소재지

    [관계 예시]
    인물 → 동원됨 → 사업장 / 인물 → 참여함 → 재판 / 기록물 → 증거 → 재판
    ```

□ 기관별 데이터 연계 3단계 전략

| 단계 | 대상 | 연계 방식 |
|------|------|-----------|
| 1단계 | 기술 미보유 민간단체 | 직접 디지털화 후 중앙 DB 등록 |
| 2단계 | DB 보유·API 미개방 | CSV/XML 정기 이전(협약) |
| 3단계 | Open API 가능 | 실시간 API 연계(독도아카이브·아카이브814 등) |
