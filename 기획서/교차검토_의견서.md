### [Ⅲ장 → JW 섹션에 대한 의견]

**문제**: 소버린AI 논거와 기술 설계 간 연결 부재

Ⅰ장에서 "소버린AI 전환 시대에 발맞춘 강제동원 역사의 사회적 기억 기반 구축"을
사업의 핵심 정책 당위성으로 제시했으나, Ⅲ장 기술 설계 파트 어디에도 실제로
'어떤 AI 모델을 쓸 것인지', '국내 모델을 쓸 것인지 해외 모델을 쓸 것인지'에 대한
언급이 없음.

소버린AI를 표방하면서 실제 구현에서 해외 상용 AI 모델(GPT 계열 등)을 활용할 경우
정책 논거와 모순 발생. Ⅲ장에 AI 모델 선택 원칙(국내 오픈소스 모델 우선,
국내 클라우드 인프라 활용 등)을 명시해야 논거 정합성 확보됨.

**수정 요청**: Ⅲ장 3절(AI 기반 검색·연결 시스템)에 "소버린AI 원칙에 따른
AI 모델 선택 기준" 항목 추가 필요.

### [Ⅳ장 → SW 섹션에 대한 의견]

**문제**: 예산 규모 당위성과 배경의 연결 미흡

18억 원이라는 예산이 왜 적정한지에 대해 Ⅳ장은 유사 사업 비교표를 제시하고 있으나,
Ⅰ장에서 강조한 '기록 소멸 위기'의 긴급성과 예산 규모가 논리적으로 연결되지 않음.

예) "에고 기록물이 매년 폐기되고 있다"는 위기 서술이 있다면,
"이를 막기 위해 1단계에 집중 투입이 필요하다"는 논거로 예산 전반부 집중 배분을
정당화해야 하나 현재 예산은 6년 균등 배분 구조.

**수정 요청**: Ⅳ장 3절(예산 산출 근거) 서두에 Ⅰ장의 위기 논거와 연계한
"1단계 집중 투자 필요성" 설명 단락 추가. 또한 1단계(2027~2029) 자료 수집·
디지털화 예산 비율을 2단계 대비 상향 조정하는 방안 검토 필요.

### [Ⅴ장 → YK 섹션에 대한 의견]

**문제**: 한일 역사갈등 서술과 일본 기관 협력 전략 간 긴장 미해소

Ⅰ장에서 일본의 조직적 역사부정론 확산(외무성 홍보, 군함도 부정 사이트 등)을
강하게 서술한 반면, Ⅴ장은 일본 시민단체와의 협력을 사업의 핵심 축으로 제시함.
독자(정부 심사자)가 "일본이 역사를 부정하는데 왜 일본 기관과 협력하나"라는
의문을 가질 수 있음.

일본 정부와 일본 시민사회의 역할을 명확히 분리하는 설명이 필요.
즉, "역사부정은 일본 정부의 공식 입장이지만, 일본 시민사회는 한국과 공동으로
피해 진상규명 운동을 30년간 전개해온 협력 주체"임을 Ⅰ장 또는 Ⅴ장에서 명시해야 함.

**수정 요청**: Ⅰ장 3절(역사부정론 현황) 말미에 "일본 시민사회의 대항 역할"
단락 추가. Ⅴ장 2절(국제 협력)에도 "일본 정부-시민사회 분리" 설명 보강.

### [Ⅲ장 → JW 섹션에 대한 의견]

**문제**: 실제 자료 포맷 다양성이 기술 설계에 미반영

Ⅲ장 디지털화 기술 항목이 OCR(문서), STT(음성), 영상 인코딩으로 구분되어 있으나,
Ⅱ장에서 명시한 실제 자료 포맷의 복잡성(카세트테이프·VHS·필름 슬라이드·
16mm 필름·손으로 쓴 일본어 필기체 문서 혼재)에 비해 기술 대응이 단순화되어 있음.

특히 다음 항목에 대한 별도 기술 대응이 누락됨:
- 노후 자기매체(카세트·VHS)의 물리적 보존처리(Preservation Transfer) 기술
- 일본어 필기체 및 변체한자 OCR (일반 OCR 엔진으로 처리 불가, 전문 모델 필요)
- 필름 슬라이드 전문 스캐너 운용 (일반 문서 스캐너와 장비·비용 구조 상이)

**수정 요청**: Ⅲ장 1절에 매체 유형별 보존처리 기술 항목 추가.
특히 노후 자기매체 항목과 필기체 전용 OCR 모델 개발 필요성 명시.

### [Ⅳ장 → SW 섹션에 대한 의견]

**문제**: 디지털화 단가가 자료 규모 대비 과소 산정 가능성

Ⅱ장에서 제시한 자료 총량:
- 소송기록 15만 쪽, 시민사회 기록 10만 쪽, 피해기록조사철 2만 쪽 → 합계 27만 쪽
- 구술 700시간, 사진·필름 다량

Ⅳ장 예산에서 자료 수집·디지털화 예산은 연 6천만 원(6년 합계 3.6억).
단가를 스캔·OCR 기준 100원/쪽으로 가정해도 27만 쪽 = 2,700만 원이나,
전문가 교정(OCR 후처리), 필기체 전사, 번역 병행 시 실질 단가는 500~1,000원/쪽.
→ 27만 쪽 × 500원 = 1억 3,500만 원 이상 필요 추정.

구술 변환도 700시간 전체를 6년 내 처리 시 전사·교정 포함 시간당 10~15만 원
기준으로 7~10억 원 규모. 예산 전체(18억)와 맞먹는 수준.

**수정 요청**: Ⅳ장 예산표에 자료 유형별 단가 산출 근거를 명시하고,
6년 내 처리 가능한 현실적 목표량과 우선순위를 재조정할 필요. 전체 디지털화를
6년 목표로 잡기보다 핵심 자료 집중 처리 후 중장기 계속 사업으로 설계 검토.

- 홋카이도 탄광 관련 지방 기록관: 탄광 강제노동 피해자 관련 기록 소장
- 사할린 한국인 관련: 러시아 국가 기록관 연계 가능성 (사할린 동원 피해자 다수)

국제기구 자료 접근 전략 추가.

### [Ⅳ장 → SW 섹션에 대한 의견]

**문제**: 1년 안에 온톨로지 설계 → DB 구축 → 검색엔진 개발 일정 과밀

현재 로드맵:
- 2027년: 온톨로지 설계 + 용어사전 구축
- 2028년: 원문DB 구축 + 검색엔진 개발 (베타)

온톨로지 설계는 도메인 전문가(역사학)와 기술 전문가(시맨틱 웹)가 수개월 협의해야
확정되는 작업. 2027년 한 해에 온톨로지 설계, 표준 확정, 용어사전 3개 언어
구축까지 완료하고, 2028년에 바로 이를 기반으로 DB 개발에 들어가는 것은
설계 변경 리스크가 높음.

권장 일정 조정:
- 2027 상반기: 자료 현황 조사 + 요구사항 분석
- 2027 하반기: 온톨로지 초안 설계 (전문가 검토)
- 2028 상반기: 온톨로지 확정 + 파일럿 DB 구축 (100건 시범)
- 2028 하반기: 검색엔진 개발 착수

**수정 요청**: Ⅳ장 2027~2028년 일정을 반기(상/하반기) 단위로 세분화하여
온톨로지 확정 후 DB 개발 착수하는 순서 명시.

### [Ⅴ장 → YK 섹션에 대한 의견]

**문제**: 다기관 API 연계 현실성 미검토

Ⅲ장에서 각 소장 기관과의 API 연계를 통한 분산형 아카이브 네트워크를 설계했으나,
Ⅴ장 협력 기관 목록을 보면 국가기록원·행정안전부·국사편찬위원회 등
공공기관이 주요 자료 소장처. 이 기관들의 현재 외부 API 개방 현황:

- 국가기록원: 제한적 Open API 운영(일부 공개자료만)
- 행정안전부 과거사지원단: API 미개방
- 국사편찬위원회: 한국사데이터베이스 Open API 운영 중 (활용 가능)
- 독립기념관: API 미개방

Ⅲ장에서 제시한 "API 연계를 통한 분산형 네트워크"는 상당수 기관에서
현재 기술적으로 불가능. 단기적으로는 데이터 이전(Data Transfer) 방식이
현실적이며, API 연계는 중장기 협의 과제로 분리 설정 필요.

**수정 요청**: Ⅲ장 4절 플랫폼 아키텍처에 "데이터 연계 방식 단계별 전환"
항목 추가 (1단계: 데이터 이전 → 2단계: API 연계 추진).
Ⅴ장에도 기관별 API 개방 협의를 별도 추진 과제로 명시.

구체적 기여 방식을 명시해야 정책 심사자가 납득할 수 있음.

**수정 요청**: Ⅰ장 5절에 "소버린AI 데이터 기여 방식" 구체화 단락 추가.
예) 구축된 한국어·일본어 병렬 코퍼스, 구술 전사 텍스트 등을
국내 AI 학습 데이터로 개방하는 계획 포함.

### [Ⅱ장 → EJ 섹션에 대한 의견]

**문제**: 자료 전수 조사 없이 DB 구축 목표량 설정

Ⅱ장 4절 수집 우선순위 매트릭스에서 수집 대상 자료 목록이 제시되어 있으나
'사진·필름'의 경우 "다량 소장 (정확한 수량 조사 未완료)"로 기재됨.

Ⅳ장 2027년 산출물로 "우선수집 대상 자료 현황 전수 조사"가 이미 포함되어 있으나,
그 결과가 2028년 예산 집행에 실시간 반영되는 피드백 구조가 명시되지 않음.
즉, 조사 결과에 따라 예산 재배분이 가능하도록 유연한 예산 집행 근거를 마련해야 함.

**수정 요청**: Ⅳ장 예산 항목에 "전수 조사 결과에 따른 예산 조정 가능" 조항 및

### [Ⅲ장 → JW 섹션에 대한 의견]

**문제**: AI 모델 개발·훈련 비용이 예산에 미반영

Ⅲ장에서 강제동원 특화 NER(개체명 인식) 모델, 다국어 크로스링구얼 검색 모델,
지식 그래프 구축을 제안했으나, 이러한 AI 모델의 개발·훈련 비용은
일반 소프트웨어 개발과 달리 GPU 서버 임차, 데이터 라벨링 인력, 모델 검증 등
추가 비용이 상당함.

현재 Ⅳ장 예산에서 "시스템 개발·운영 연 6천만 원"에 이 모든 비용이 포함되어
있는 것으로 보이나, AI 모델 개발만으로 연 1~2억 수준의 투자가 필요한 경우가 일반적.

2단계(2030~2032) 예산의 시스템 개발 비율을 상향하거나,
AI 개발은 외부 연구기관(ETRI, 대학 AI 연구소 등)과의 공동연구 과제로 비용을
분산하는 전략이 현실적.

**수정 요청**: Ⅳ장 예산표에서 AI 모델 개발 항목을 독립 예산으로 분리하고,
외부 공동연구 방식 활용 계획 명시.

### [Ⅴ장 → YK 섹션에 대한 의견]

**문제**: MOU 협상 비용과 법률 검토 비용 예산 미반영

Ⅴ장 단계별 협력 로드맵에서 2027년에 주요 공공기관 MOU를 일괄 체결하는
것으로 계획되어 있으나, 다음 비용이 예산에 반영되지 않음:
- 기관별 MOU 법률 검토 및 계약서 작성 비용
- 행정안전부 판정자료 비공개 해제를 위한 법령 개정 추진 비용
- 일본 시민단체 방문 협의 외 온라인 플랫폼 구축·통역 비용

또한 행정안전부 판정자료(22만 건) 공개는 개인정보보호법·공공기록물법 등
관련 법령 정비가 선결 과제인데, 이 법제화 추진을 누가, 어떤 예산으로 할지
계획이 없음.

**수정 요청**: Ⅳ장 예산에 "협력 체계 구축 비용(MOU 법률 검토, 통역, 협의)" 항목 추가.
Ⅴ장에 행정안전부 판정자료 공개를 위한 "법령 정비 추진 과제" 별도 항목 명시.

### [Ⅲ장 → JW 섹션에 대한 의견]

**문제**: 각 기관의 기존 시스템 현실 미반영

Ⅲ장의 시스템 아키텍처는 모든 협력 기관이 표준화된 API로 연결되는 이상적 구조를
전제하나, 실제 협력 기관들의 기술 환경:
- 국가기록원: 자체 온라인 기록정보서비스(CAMS) 운영, 외부 연계 복잡
- 독립기념관: 내부 DB 존재하나 웹 서비스 API 미제공
- 민간 단체 다수: 디지털 시스템 자체가 없거나 엑셀·파일 형태로만 존재

이러한 기술 격차를 고려한 "기관별 데이터 연계 방식 다원화" 전략이 필요:
- 고도화 기관: API 직접 연계
- 중간 수준: CSV/XML 주기적 데이터 이전
- 기초 수준: 직접 디지털화 지원 후 중앙 DB 등록

**수정 요청**: Ⅲ장 4절 플랫폼 아키텍처에 기관 기술 수준별
"3단계 데이터 연계 방식" 항목 추가.

### [Ⅳ장 → SW 섹션에 대한 의견]

**문제**: 행정안전부 판정자료 공개를 위한 선행 과제 일정 미반영

행정안전부 소관 피해신고자 판정자료(22만 건)는 개인정보보호법상
'개인정보 처리 정지' 및 '공공기록물의 비공개 열람 제한' 규정으로 인해
현행법 체계에서 전면 공개가 어려운 상황.

이 자료를 사업에 활용하려면:
① 관련 법령(공공기록물 관리법, 개인정보보호법) 개정 또는 특례 조항 마련
② 행정안전부·개인정보보호위원회와의 협의
③ 피해자·유족 동의 체계 구축

이 과정이 2년 이상 소요될 수 있어 Ⅳ장 로드맵에 "법령 정비 선행 과제"로
2027~2028년에 별도 트랙으로 명시 필요.

**수정 요청**: Ⅳ장 1절 1단계 추진 내용에 "판정자료 공개를 위한 법령 정비 추진"
별도 과제로 추가.

### [Ⅰ장 → DS 섹션에 대한 의견]

**문제**: 일본 기관과의 협력 가능성에 대한 근거 제시 미흡

Ⅰ장에서 일본 정부·우익 단체의 조직적 역사부정을 상세히 서술한 반면,
일본 시민사회가 실제로 한국과 30년 이상 연대해온 구체적 역사와 성과를
거의 언급하지 않음. 이 때문에 보고서를 읽는 심사자 입장에서 Ⅴ장의
일본 시민단체 협력 방안이 낙관적으로 보일 수 있음.

Ⅰ장 또는 Ⅴ장에서 다음을 보강할 필요:
- 한일 시민연대의 구체적 성과 (1990년대 이후 공동 소송 지원, 공동 조사 활동)
- 일본 협력 단체들과 민족문제연구소의 현행 협력 관계 수준
- 협력 지속의 장애 요인(고령화, 재정, 양국 외교 환경) 및 대응 방안

**수정 요청**: Ⅰ장 3절 말미에 "일본 시민사회의 역할과 한일 연대 현황" 단락 추가.
Ⅴ장 2절에 기존 협력 성과를 근거로 한 협력 실현 가능성 설명 보강.
